Samachar

A personalized digital newspaper that brings together sign-in, saved interests, article aggregation and scheduled delivery.

The problem

Readers move between many news sources to find stories that match their interests. Samachar organizes that process around a reader’s chosen topics and delivers a digital digest through an automated workflow.

How the product works

Users sign in through Google OAuth2. Firebase stores their preferences. The application fetches articles from an external news API according to those interests, assembles a digest and sends it through email. The public repository also documents SMS notifications.

Sign in→Save interests→Fetch stories→Assemble digest→Deliver

My contribution

I built the full-stack flow from authentication and preference storage to data aggregation and scheduled delivery. This work connects API integration, user state and automation in one product.

Result & source

The repository contains the application files, requirements and documentation for the product. It demonstrates a working path from a reader’s interests to a personalized digital newspaper.
